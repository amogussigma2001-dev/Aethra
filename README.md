# Aethra — приложение для Android

Обычное приложение: весь код внутри APK. Не открывает сайты и не просит входить ни в какие аккаунты.
Установил, открыл, зарегистрировался (имя + юзернейм).

## Важно про общение между телефонами
Чтобы разные люди видели друг друга и переписывались, нужна общая база данных.
- **Без неё (по умолчанию)** — всё работает, но данные хранятся только на одном телефоне.
- **С ней** — настоящий мессенджер. Это бесплатно и занимает 3 минуты (Firebase, не Supabase):
  1. console.firebase.google.com → Add project (любое имя, Google Analytics выключи).
  2. Слева Build → Realtime Database → Create Database → любой регион → **Start in test mode**.
  3. Вкладка Rules → вставь `{ "rules": { ".read": true, ".write": true } }` → Publish.
  4. Наверху вкладки Data скопируй адрес вида `https://....firebaseio.com` (или `...firebasedatabase.app`).
  5. На GitHub открой `config.js` (карандаш), вставь адрес между кавычками в `FIREBASE_URL: ""` → Commit.
  6. Сборка запустится сама. Скачай новый APK и поставь на ВСЕ телефоны.
Правила выше открывают базу всем, у кого есть адрес. Для небольшого круга друзей нормально, но адрес никому не давай.

## Админка и аккаунты
- Админ — аккаунт с юзернеймом `vitae_6`. Зарегистрируй его первым.
- Больше 2 аккаунтов зарегистрировать нельзя (лимит меняется в админ-панели, вкладка «Люди»).

## Как собрать APK (GitHub)
С компьютера: создай репозиторий, распакуй zip и перетащи ВСЁ (включая папку `.github`) → Commit.
С телефона: Add file → Upload files: `index.html`, `shim.js`, `config.js`, `capacitor.config.json`, `package.json`, три `icon-*.png`. Затем Add file → Create new file с именем `.github/workflows/build-apk.yml` и вставь в него содержимое файла `build-apk.yml`.
Если в репозитории остались старые файлы — замени их новыми.
Дальше: вкладка Actions → дождись зелёной галочки (≈8 минут) → справа Releases → Aethra v… → скачай **Aethra.apk** и установи.

## Что не входит
Уведомления приходят, пока приложение открыто или недавно было свёрнуто. Настоящие пуш-уведомления при полностью закрытом приложении требуют отдельного сервера.
Ошибка сборки: Actions → красный запуск → скопируй текст ошибки и пришли мне.
